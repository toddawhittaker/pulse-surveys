# E9-06 — attempts

## 2026-10-12 — the build (builder-light)

Built `services/people.py`, `api/admin.py` (18 routes, each behind
`require_admin`, each write behind `csrf_verified_admin`), `schemas/admin.py`,
six import sentences in `copy/admin_people.py`, the router registration, the
regenerated openapi and wire files, ADR 0204 and the SPEC §13 lines.

First design of the import treated a file as the whole mapping table. Dropped
it before testing: on the shared test database an import would unmap other
tests' rows, and any concurrent mapping write would refuse every apply. A file
now states only the records it names; a blank lead unmaps (ADR 0204).

Found while writing ADR 0204: a file of new people alone had an empty digest
state, so it could be applied twice. The digest now also covers people already
bearing a new line's name; tested.

Mutations checked: a dry run that commits instead of rolling back fails two of the three
import tests it was run against; removing the digest check fails the stale-apply test.

Left out: "a revoked session is refused on an admin route with the
expired-token 401" waits for E9-04's revocation (orchestrator adds it).
