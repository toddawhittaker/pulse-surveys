## 3. Three tests cannot pass against `classification.task` as an enum (disputed)

`test_the_verdict_check_is_per_task_in_both_directions`,
`test_the_application_connection_is_refused_a_direct_write_to_either_route_table`
and `test_identity_grants.py::test_a_moderation_verdict_written_around_the_definer_is_refused_to_every_role_but_its_owner`
insert `CAST(:task AS text)` into `classification.task`, which is the Postgres
enum `classification_task` (ADR 0055). Postgres has no assignment cast from text
to an enum, so every one of those inserts fails with `DatatypeMismatch`,
including `pulse_app`'s validity insert, which E6-01 does not touch. With only the
cast changed to `classification_task` (a scratch pytest plugin patching the
module constant at collection, no test file touched), all three pass. Filed
`docs/disputes/E6-01-01.md` rather than reversing ADR 0055's enum to fit an
incidental cast. Mutation check with the cast patched: the trigger removed from
`moderation_routing_v001.sql` reds the grants test's `pulse_app` refusal.
Separately, `section_week_moderated` forced true (and the cut's set emptied)
reds four tests across the no-verdict, summary and generated-world modules.
