## Item 4 — worked

`scripts/ci/check_image_contents.sh`, the name the test module's constant
already expected, so the constant did not have to move. It plants one file per
re-exclusion in `backend/app/ai/prompts/`, builds the runtime image from
`backend/Dockerfile` with the same context Compose uses, lists the installed
prompts directory from inside the image, and fails if any planted name is there.

Wired into `.github/workflows/ci.yml`'s `docker` job right after "Build all
images", into `docker-build` right after `$(COMPOSE) build`, and into both
`bash -n` lists (`ci-selftest` and `make selftest`).

Measured rather than reasoned, each mutation confirmed landed first:

- clean tree: passes in 0.6s, a full cache hit, listing `README.md` and
  `validity.v1.md`
- all four re-exclusion lines deleted: fails in 8.7s naming all four planted
  files
- only `backend/**/*.rej` deleted: fails naming exactly the `.rej` file
- inspection path pointed at the parent package directory (listing non-empty,
  control absent): the positive control fires
- inspection path misspelled: the listing cannot be read and it says so, rather
  than treating an unreadable listing as an empty one

The planted files and the probe image are cleaned up on every exit, verified
after both a passing and a failing run.

`--load` on the build is not optional: CI's builder is the docker-container
driver from `docker/setup-buildx-action`, which puts nothing in the image store
without it, and the script runs the image afterwards.

MISTAKES entry 34 earned its first prevention here and is bumped 0 → 1: the
natural way to write the inspection is `docker run … | grep -qF`, which reports
"no stray file found" whenever `docker run` itself fails.

## Note for whoever picks this up cold

The hook that guards the test wall matches the string `tests/` anywhere in a
Bash command, not just in the path being written. Writing this file with a
heredoc that quoted the three failing test paths was blocked. Use the Write
tool for this file, or keep test paths out of the command line.
