**Two things worth knowing next time in this worktree.**

- The `deny-test-edits.sh` hook matches the whole command positionally, so
  `pytest tests/unit tests/integration -q > somefile` is blocked — the `>` sits
  after a `tests/` path and reads as a redirect into a test file. Run that one
  bare and read the tail of its printed output; do not pipe it to `tail`, which
  would report `tail`'s exit status (`docs/MISTAKES.md` entry 34).
- A peer committed to this branch mid-session (`fb69184`, a docstring change in
  `tests/unit/test_dev_console_exposure.py`). Check `git log` around every
  commit here.
