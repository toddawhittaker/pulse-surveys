## Attempt 2 — 2026-08-22 — the sweep and the gates — succeeded

every code fact ADR 0078 and 0079 cite, the spec sentences ADR 0025's and 0044's
amendments claim, both repointed citations, every `carried-from-e0` fact, the

tolerant gate and a gate looking in the wrong place print the same green line.

sentences were also loose about *where* the TypeScript is and were tightened
against a directory listing.
