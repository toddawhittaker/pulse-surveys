**The e2e serving mechanism, settled before the browser half.** The Compose
stack serves `/opt/pulse/frontend`, baked into the api image by
`backend/Dockerfile` (`COPY --from=frontend /src/frontend/dist /opt/pulse/frontend`,
`ENV FRONTEND_DIST=/opt/pulse/frontend`). `docker-compose.override.yml` mounts
only `./backend`, so a frontend edit in this worktree is invisible to the
running stack, and there is no documented worktree-serving path — `make e2e`
assumes the stack is already up and does not build. The file-level swap is
therefore `npm run build --workspace frontend` here followed by
`docker cp frontend/dist/. pulse-surveys-api-1:/opt/pulse/frontend`. Starlette's
`StaticFiles` resolves each request against the directory, so no restart is
needed, no image is rebuilt and no container is stopped. The original directory
is copied out first and restored afterwards.
