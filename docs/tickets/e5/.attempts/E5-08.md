**One addition beyond the work order, and why.** The work order named four
fixtures; there are five. A member that is unsuppressed and carries `mean: null`
is a real payload shape — the trend chart's silent week in the workload pair's
form — and it is not a suppression: the set is large enough to report on, and
this week has nothing from it. Saying "the set behind this figure is too small"
there would state something untrue about the set, so the two cases get two
sentences and the fifth fixture proves the component tells them apart.

**ADR 0169 written** (`docs/adr/0169-a-withheld-comparison-statistic-is-a-sentence-in-the-column.md`),
using the number pre-assigned to this ticket. The spec and the design brief both
stop short of saying what a suppressed *statistic* looks like and the prototype
has no suppressed state, so the treatment is contestable and recorded: words in
the cell rather than a dash or a digit, two reasons kept apart, the reason on
screen rather than only in the accessible text, and a complete label on every
figure instead of a column header row.

**Two judgment calls worth a reviewer's eye.**

1. The comparison column is labelled "comparable courses" where
   `instructor_report_trend.legend_comparison` says "Comparable {weeks}-week
   courses". The trend chart is handed the section's `length_weeks` and this
   component is not, and a label naming a length it was never given would be a
   claim rather than a fact. The term is the same; the length is the half this
   surface cannot honestly write. If E5-10 wants the length here, it arrives as
   a prop and the label keys change with it.
2. The three-column grid hangs on one modifier class, pinned in the tests by
   class name because jsdom applies no stylesheet. A rename has to move the pin
   with it.
