**Three decisions the work order did not settle.**

1. **Where the fixtures live.** The work order names `comparisonSetFixtures.ts`
   beside the components. Put there, its course labels and set names are read
   as shipped strings by the ungoverned-string sweep, which excuses a
   test-support module only by naming it in `EXCLUDED_SUPPORT_MODULES` —
   `tests/fixtures/`, another heavy path. So the module sits in
   `frontend/src/api/`, beside the contract it mirrors, and the gap that
   creates (no sweep reads it) is in `deferred.md` with E5-13 as owner.
2. **The cookie reader moved.** `api/student.ts` held a private `readCookie`
   and the `X-Pulse-CSRF` constants, and this is the second write client in the
   directory. Two readers for one cookie is `docs/MISTAKES.md` entry 13, so the
   reader moved up into `lib/session.ts` as `csrfHeader()` beside
   `authorizationHeader()`, and both clients call it. `api/student.ts` keeps
   every sentence of its reasoning, pointed at the new home. This touches a file
   the work order did not name; it is 13 lines and the alternative was shipping
   the duplication.
3. **"A child of the existing `/leadership`"** is built as an address rather
   than as a nested route. Every route in `router.tsx` is declared flat off the
   root, the leadership landing renders no outlet, and nesting would change what
   that page renders for a shape nothing reads. The reasoning is in the route
   table beside the two declarations.

**Two departures from the work order's letter, both small.** Decision 2 asks
for a notice "naming how many were removed and which"; there are two entries
rather than one, because "1 courses" is a sentence nobody wrote on purpose.
And decision 4's honest sentence about no report rendering a named set stands
in the page's own intro rather than inside the preview line, so that it is
said once per page rather than once per set.

**One limit of the level-change assertion, said plainly.** Decision 2's
"members whose level matches the new level survive" is asserted by choosing the
same level again with courses ticked: because the picker only ever offers
courses of the chosen level, a chosen course of a *different* level cannot be
composed through the form, and the contract does not let one arrive in an
existing set either. So the surviving half is real and driven, and it is driven
on the only path that reaches it.
