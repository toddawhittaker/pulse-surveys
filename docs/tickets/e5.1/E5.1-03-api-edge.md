# E5.1-03 — The API edge holds one job per module

**ID:** E5.1-03
**Branch:** `e5.1/api-edge`
**Depends on:** none
**Lane:** heavy
**Size:** M
**Security-relevant:** it edits `api/deps.py`, where every route's gate lives,
and adds the origin check to the development clock routes.

## Context

The API edge has collected copies and stray jobs:

- The four entry pages' sentences live outside the copy registry
  (`backend/app/api/deps.py:476-830`), so the §4.1 items 4 and 5 sweep never
  reads them. The instructor gate's 401 sentence is still a literal
  (`NOT_AN_INSTRUCTOR`, `deps.py:363`), a carried entry.
- The clock row is written in a router (`backend/app/api/dev.py:857`, `:1269`,
  `:1442`), and the clock routes have no origin check (`dev.py:1386-1387`, a
  carried entry).
- Three guard bodies are copies of each other (`deps.py:289`, `:369`, `:428`).
- The token CSS is copied (`deps.py:611-620`, `dev.py:371-380`).
- `_person_of` is defined twice (`backend/app/api/instructor.py:233`,
  `backend/app/api/leadership.py:291`), the `_person_of` half of a carried
  entry.
- `LTI_LOGIN_COOKIE` is dead (`deps.py:170`), and the "both doors" docstring
  (`deps.py:198`) describes helpers that belong to the web door.

Read first: SPEC §4.1 items 4 and 5, §13, `design/tokens.css`, and
`docs/MISTAKES.md` entry 47 (a route's gate was discarded at dispatch).

## Owns

- `backend/app/api/deps.py`, `backend/app/api/auth.py`,
  `backend/app/api/dev.py`
- `backend/app/services/clock.py`
- the new `backend/app/copy/entry.py`, and `backend/app/copy/instructor_report.py`
- the `_person_of` lines in `api/instructor.py` and `api/leadership.py`
- `tests/unit/test_the_shipped_copy_inventory_holds_to_items_four_and_five.py`
- ADR **0186**, only if deciding whether the entry pages owe a
  confidentiality line is contested. If 0186 goes unused, E5.1-09 records the
  gap in the ADR README.

## Done when

1. **The entry sentences are governed.** Every sentence the four entry pages
   serve, plus `NOT_AN_INSTRUCTOR`, is a `CopyEntry` under a governed prefix.
   The items 4 and 5 sweep reads them. A forbidden word planted into one of
   them turns the sweep red.
2. **No literal is left behind.** The ungoverned-string sweep covers
   `api/deps.py` and finds nothing.
3. **The dev clock routes refuse cross-site posts.** `/dev/clock` and
   `/dev/clock/clear` answer 403 to a cross-origin POST and still work from the
   same origin. Both directions are driven over HTTP (entry 47).
4. **One module owns the clock row.** `clock_override` is read and written
   only in `services/clock.py`, and a sweep test asserts it.
5. **The token values have one source.** Both pages use one design-token CSS
   block, and a test reads its values from `design/tokens.css`.
6. **The dead parts are gone.** One `_person_of` helper exists, its callers
   are moved, and the copies are deleted. `LTI_LOGIN_COOKIE` is gone, and the
   web door's cookie helpers live in `api/auth.py`.

## Known traps

- **A gate proven by reading the class, not the dispatch.** Criterion 3 drives
  real HTTP requests (entry 47).
- **Folding the three guards changes nothing they refuse.** The existing guard
  tests pass unmodified.

## Out of scope

- The report's own copy beyond what moving `NOT_AN_INSTRUCTOR` needs.
  E5.1-01 rewords the small-N notice in the frontend copy.
