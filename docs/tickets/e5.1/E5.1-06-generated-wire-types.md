# E5.1-06 — Frontend wire types come from the OpenAPI schema

**ID:** E5.1-06
**Branch:** `e5.1/generated-wire-types`
**Depends on:** E5.1-01 and E5.1-05, which change the wire and the API files
this ticket touches
**Lane:** light
**Size:** M
**Security-relevant:** no. The ticket changes where types come from, not what
crosses the wire.

## Context

Ruling 3: the frontend wire types are generated from OpenAPI. Only types are
generated, not a client. The generator is a pinned dev dependency, and a
check fails when the generated types are stale.

Today the types are written by hand, and the copies have spread:

- The three API modules repeat their fetch helpers (`frontend/src/api/*.ts`,
  for example `instructor.ts:411` and `:428`).
- `instructor.ts:170`, `components/StatPair.tsx:37` and
  `components/PulseTrendChart.tsx:54`, `:77`, `:96` declare the same figure
  types. The visibility check is written twice: `isDrawable` at
  `PulseTrendChart.tsx:639` and `isReportable` at `StatPair.tsx:333`.
- `PulseDivider` is defined twice (`StudentWeeklySurvey.tsx:699`,
  `InstructorMondayReport.tsx:523`), and `components/instructorReportPage.css`
  is a page stylesheet sitting among the components.

Read first: ADR 0117 (this ticket supersedes it in part), ADR 0074 (docs are
disabled outside development), SPEC §13, and `docs/MISTAKES.md` entry 8.

## Done when

1. **A pinned generator.** `openapi-typescript`, exact-pinned, generates
   `wire.gen.ts` from a committed `openapi.json`. `scripts/export_openapi.py`
   exports that file from `create_app().openapi()`. Settle whether that call
   works with docs disabled before building on it (ADR 0074; entry 8).
2. **Both stale cases go red.** A pytest fails when `openapi.json` is stale,
   and a frontend unit test fails when `wire.gen.ts` is stale. Each is shown
   red against a planted schema change. Both run inside existing CI jobs, so no
   workflow edit is needed. If the owner wants a separate CI step, that is a
   `process/` PR.
3. **No hand-declared wire types remain.** Every wire type in `api/*.ts` is an
   alias of, or picks from, a generated type, and a sweep asserts that.
4. **The shared helpers exist once.** The fetch helpers live in `lib/http.ts`.
   One figure type and one `isShownFigure` serve the chart and the stat cell.
   `PulseDivider` is one component. The page stylesheet sits under
   `routes/instructor/`.

## Known traps

- **Prescribing a fix without probing it.** Run `create_app().openapi()` with
  production settings before designing around it (entry 8).
- **Fail-closed reads.** `isShownFigure` keeps `isDrawable`'s fail-closed
  reading of a malformed figure; merging the two must not loosen either.

## Out of scope

- A generated client or query hooks. Ruling 3 generates types only.
- Renaming the shared component stylesheets. Left out until E8 reuses a
  component.
