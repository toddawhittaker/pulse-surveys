# E5.1-08 — Records match the code

**ID:** E5.1-08
**Branch:** `e5.1/records-match-code`
**Depends on:** E5.1-03 and E5.1-06, which add modules §13 must draw
**Lane:** light
**Size:** S–M
**Security-relevant:** no code changes beyond one test. ADR 0089 gains a
recorded security residual.

## Context

The records have drifted from the code:

- **SPEC §13** (lines 385-518) draws modules that do not exist and misses ones
  that do. Examples: `frontend/Dockerfile` (line 475) does not exist; the
  generated client (line 482) and `generate_client.sh` (line 512) were never
  built; and `lti/nrps.py` (line 448) is drawn while the roster sync lives in
  `services/roster_sync.py`.
- **ADR 0073** line 3 says "Accepted" with no superseded-in-part line, although
  ADR 0089 superseded part of it.
- **ADR 0132** line 103 says that is "the only edge from `lti/` into
  `services/`". `backend/app/lti/launch.py:73` already contradicts it.
- **ADR 0155** lines 152 and 216 say "one function-local import". There are
  eight.
- **Login request forgery.** The cookieless launch is not bound to the
  browser that started it (`backend/app/api/lti.py:149`,
  `backend/app/lti/in_flight.py:43`). The fix is carried to E13; this ticket
  records the residual in ADR 0089 meanwhile.

Read first: SPEC §13 whole, ADRs 0073, 0089, 0132 and 0155, and
`docs/adr/README.md`.

## Owns

- SPEC §13
- `docs/adr/0073`, `0089`, `0132`, `0155`, and those rows of
  `docs/adr/README.md`
- the new unit test for §13

## Done when

1. **§13 matches the tree.** A unit test asserts that every module under
   `backend/app/` and every directory under `frontend/src/` is named in §13.
   Each module §13 draws that does not exist cites its ADR.
2. **The ADR statuses and claims are true.** ADR 0073's status line and its
   README row say "superseded in part by 0089". The 0132 and 0155 sentences
   are true.
3. **The forgery risk is recorded.** ADR 0089 records the login-forgery
   residual, with E13 as owner.

## Known traps

- **Grep the fact, not the record.** Count the function-local imports and the
  `lti/` to `services/` edges in the code before rewriting the sentences.

## Out of scope

- Moving the seal or the summary job out of `reporting.py`. Only ADR 0155's
  stale sentences are fixed here.
- Fixing login request forgery. That is E13's.
