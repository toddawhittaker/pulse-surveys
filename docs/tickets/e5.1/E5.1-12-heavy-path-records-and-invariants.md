## Part B: tests

1. **The small-N object carries only its two fields.** In
   `test_the_report_payload_carries_small_n_per_stream.py` (invariant): for one
   suppressed stream and one shown stream, `set(streams[s].small_n) ==
   {"suppressed", "threshold"}`, and the same equality on
   `SmallNView.model_fields` (`backend/app/schemas/report.py` about line 248).
2. **The notice shows no count, as an invariant.**
   `tests/unit/test_the_small_n_notice_states_the_threshold_and_no_count.py`
   gains module-level `pytestmark = pytest.mark.invariant`. If the
   denial-module filename guard's `DENIAL_NAME_SHAPES` should cover the
   `_no_count` shape, add it with planted samples as that guard's own tests do.
3. **An open week never feeds another week's figures.** In the invariant test
   `test_a_course_week_whose_window_is_still_open_is_refused`, also assert the
   open course week is absent from the served closed week's `published_weeks`
   and from both streams' trend points (`reporting.py` `_published_weeks`,
   about line 1073).
4. **A student's read refuses an enrollment that is not live today.** In
   `test_the_student_read_path_names_nothing_outside_the_enrollment.py`
   (invariant): an enrollment that ended yesterday, and one that starts
   tomorrow, each gets the same answer as no enrollment; one live today reads
   (control).
5. **A whitespace-only comment is not a commenter.** An invariant case: four
   real commenters plus one whitespace-only answer inserted directly (past the
   write-path strip) leaves the stream suppressed; five real commenters show it
   (control).
6. **The E5.1-02 migration round-trips.** A downgrade test for revision
   c5e8a1f3b9d4 modelled on
   `test_the_summary_job_grants_are_given_back_by_a_downgrade.py`: after
   downgrade the definer function and the table are gone and the definer role
   holds no privilege; re-upgrade restores them.

Each new assertion must go red under a named mutation of the code it guards.
These tests pin behaviour that already holds, so they are expected green.
