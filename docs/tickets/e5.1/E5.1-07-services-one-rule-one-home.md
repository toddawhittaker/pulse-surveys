# E5.1-07 — One copy of each services rule

**ID:** E5.1-07
**Branch:** `e5.1/services-one-rule-one-home`
**Depends on:** E5.1-01 and E5.1-05, which also edit `reporting.py` and
`grading.py`
**Lane:** light
**Size:** M
**Security-relevant:** indirectly. The live-on-a-day rule decides who counts
as enrolled, so the copies must agree before they are folded.

## Context

Several services rules are written more than once. A copy that drifts is a
rule that means two things. The copies, all under `backend/app/services/`:

- **Question set:** `survey_read.py:360`, `submissions.py:238`
- **Course week:** `survey_read.py:342`, `reporting.py:1096`
- **Live on a day:** `survey_read.py:166-181`, `submissions.py:218-227`,
  `grading.py:1225-1233`
- **Staff filter:** `grading.py:1234`, `reporting.py:1729`
- **Course label:** `survey_read.py:253`, `reporting.py:1738`, and the
  named-set composer in `comparison_sets.py`. This closes the course-label half
  of a carried entry; E5.1-03 closes the `_person_of` half.

Read first: SPEC §2.2 and §3.4, §13, and `docs/MISTAKES.md` entry 13 (a hazard
handled in only one of the places facing it).

## Owns

- `backend/app/services/survey_read.py`, `submissions.py` and
  `comparison_sets.py`
- `backend/app/services/section_codes.py` and `enrollment_windows.py`
- `backend/app/services/grading.py` and `reporting.py` (these copies only)

## Done when

1. **One question-set rule.** `current_questions` returns the set and its
   questions, and `survey_read`, `submissions` and grading all use it.
2. **One course-week rule.** One `course_week_of` in `section_codes.py`.
3. **One live-on-a-day rule.** One `live_on(day)` expression and one
   `without_staff` helper in `enrollment_windows.py`.
4. **The landing rule agrees.** A test asserts that `authz._A_LIVE_ENROLLMENT`
   (`authz.py:1616`, which stays as it is so the ticket stays light) agrees with
   `live_on` on the boundary days: `started_on = day`, `ended_on = day`,
   `ended_on = day - 1`, and a null end.
5. **One label composer.** Its three callers are moved.
6. **The copies are gone, and nothing else moved.** A test finds each private
   copy deleted, and the behaviour suites pass unmodified.

## Known traps

- **Copies that look alike but differ.** Diff the copies before folding them.
  If two disagree on a boundary day, stop and raise it; do not pick one
  silently.
- **A light diff reaching a heavy path.** Editing `authz.py` makes this
  ticket heavy. Criterion 4 only reads it.

## Out of scope

- The item total that uses today's question set. That is carried to the
  ticket that adds a second question set.
