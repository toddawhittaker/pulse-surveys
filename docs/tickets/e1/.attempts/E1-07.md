## 2. The mint surface: `?defect=` and `app.wrong_launches` (ffc96ae) — worked

`mock-lms/app/wrong_launches.py`: `WrongLaunchMinter`, one instance per app,
dispatching on a name in `ALL_SELECTORS` (the fifteen wrong-launch names plus
the three near-miss/edge fixture names) to one `MintedResponse` each. Every
branch is built off the same `id_token_claims(resolved, settings)` a correct
launch already produces, so a defect is a one-claim (or one-key, or one-
signature) difference from the happy path rather than a second construction
of a launch.

`mock-lms/app/signing.py` gained three things `app.wrong_launches` needed and
ADR 0035 says belong beside the RS256 arithmetic rather than scattered:
`public_key_material()` (the RFC 7638 canonical `e`/`kty`/`n` bytes, refactored
out of `key_id` and reused as `hs256_confusion`'s HMAC secret),
`unsigned_compact_jws` (`alg: none`), and `hs256_compact_jws` (HMAC-SHA256 via
stdlib `hmac`, never a crypto library).

`mock-lms/app/main.py`: the authorization route reads `?defect=` off the URL
regardless of method; absent, it runs the same two lines it ran before this
ticket. Verified additive by running the full existing `test_mock_lms_
launch.py` suite unmodified before writing a single new test — 26/26 passed
against the new code with no defect selector ever exercised.

`ruff format`, `ruff check`, and `mypy mock-lms/app` clean throughout.

## 3. Mock-side tests, one per selector, plus a completeness sweep (b08bc23) — worked

`tests/integration/test_mock_lms_wrong_launches.py`: 38 tests. One per named
defect and per near-miss/edge fixture, each decoding the artifact and
asserting the *specific* wrongness plus a canary claim proving the check has
not gone blind (`docs/MISTAKES.md` entry 3); a parametrized sweep over every
declared selector proving each is producible at all; the byte-identical
happy-path proof (criterion 2); and a refusal test for an unrecognised
`?defect=` value.

Driven around `MockPlatform.mint` rather than through it — that fixture has
no `?defect=` parameter and this ticket does not add one, per the work
order's instruction that the mints live on the mock. Claims are decoded by a
small local helper rather than by importing `tests/fixtures/lti_platform.py`,
matching the existing suite's stated reason for never importing a fixtures
module by name from a test module.

**Spot-checked by mutation before trusting the green run** (not a battery —
light lane — but MISTAKES entry 3 earned four direct checks given how much
of this ticket rests on "the artifact really carries the defect"):
- `hs256_confusion`'s secret perturbed by one byte → red on the HMAC
  comparison.
- `reused_nonce`'s cache bypassed (always mint fresh) → red on the
  byte-identity comparison, with a real 1.1-second gap between the two calls
  so a coincidental `iat` match could not explain a false pass.
- `right_key_tampered_claims`'s tamper step short-circuited (return the
  correct token unmodified) → red on the `sub`-suffix assertion.
- `main.py`'s `if defect is None` branch disabled → red, failing loudly
  through `MockPlatform.read_authorization_response`'s own "no id_token
  produced" failure rather than silently.

All four reverted with `git checkout --` after confirming red, then the full
38-test file and the pre-existing 129 other `mock_lms`-marked integration
tests re-run together: 167 passed.

## 4. ADR 0088 (18755fe) — worked

`docs/adr/0088-a-query-parameter-selects-one-wrong-launch-per-mint.md`: the
selector shape, the one-defect-per-mint rule and its shared vocabulary tuple,
and where `reused_nonce`'s replayed bytes come from — the spec is silent on
a wrong-launch mint entirely and the ticket names three genuinely open
choices. States its own cost: the vocabulary is copied into every consumer
outside `mock-lms/`, because both mocks are packages named `app` (the same
collision ADR 0039 records for mypy), and closes with two 0035-derived
performance choices (`reused_nonce`'s cache and `foreign_signature`'s lazy
key) that avoid double-paying the mock's own suite-wide startup cost. Index
row added to `docs/adr/README.md`.
